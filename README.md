# সুফ্ফা সুপারশপ — হোস্টিং গাইড

## ফাইল
- `index.html` — পুরো ওয়েবসাইট (একটাই ফাইল, সব CSS/JS ভেতরেই আছে)
- `logo.svg` — ডিফল্ট লোগো (চাইলে নিজের লোগো দিয়ে বদলে ফেলো, ফাইলের নাম একই রাখো: `logo.svg`)

## কীভাবে হোস্ট করবে (সবচেয়ে সহজ উপায়গুলো)

### ১. Netlify (সবচেয়ে সহজ, ফ্রি)
1. https://app.netlify.com/drop এ যাও
2. এই zip থেকে বের করা পুরো ফোল্ডারটা (index.html + logo.svg) ড্র্যাগ করে ছেড়ে দাও
3. সাথে সাথে একটা লাইভ লিংক পেয়ে যাবে

### ২. GitHub Pages
1. একটা নতুন GitHub রিপোজিটরি বানাও
2. `index.html` ও `logo.svg` আপলোড করো
3. Settings → Pages → Branch: main → Save
4. কয়েক মিনিটের মধ্যে `https://username.github.io/repo-name` এ লাইভ হবে

### ৩. Vercel
1. vercel.com এ অ্যাকাউন্ট খুলে "Add New Project" → "Deploy" এ zip আপলোড করো

### ৪. নিজের হোস্টিং/cPanel থাকলে
- `public_html` ফোল্ডারে `index.html` ও `logo.svg` আপলোড করে দাও, ব্যাস।

## গুরুত্বপূর্ণ কিছু কথা

- **এডমিন পাসওয়ার্ড**: বর্তমানে `suffa2026`। বদলাতে চাইলে `index.html` ফাইলে খুঁজো:
  `const ADMIN_PASSWORD = 'suffa2026';`
  এখানে নতুন পাসওয়ার্ড বসিয়ে দাও।

- **ডেটা সংরক্ষণ**: এডমিন প্যানেল থেকে যা কিছু পরিবর্তন করবে (পণ্য, দাম, স্টক, প্যাকেজ, ভ্যারাইটি) — সব সংরক্ষিত হয় **ব্রাউজারের localStorage-এ**, সার্ভারে না। মানে:
  - প্রতিটা ভিজিটরের ব্রাউজারে ডিফল্ট পণ্যের তালিকা দেখাবে (localStorage খালি থাকলে)
  - শুধু যে ব্রাউজারে এডমিন প্যানেল দিয়ে পরিবর্তন করা হয়েছে, সেই ব্রাউজারেই সেই পরিবর্তন দেখাবে
  - অর্থাৎ এটি **একজন অ্যাডমিনের জন্য উপযুক্ত ডেমো/ছোট দোকানের সিস্টেম**, কিন্তু একাধিক ডিভাইস থেকে একই ডেটা দেখতে চাইলে (যেমন সত্যিকারের মাল্টি-ইউজার ই-কমার্স সাইট) ভবিষ্যতে একটা ব্যাকএন্ড/ডেটাবেস দরকার হবে।

- **অর্ডার সিস্টেম**: গ্রাহক অর্ডার করলে এখন শুধু PDF ডাউনলোড হয় (কাস্টমারের ডিভাইসে)। তোমার কাছে অর্ডারের নোটিফিকেশন আসার জন্য এখনো কোনো সার্ভার/হোয়াটসঅ্যাপ/ইমেইল সংযোগ নেই — চাইলে এটাও যোগ করে দেওয়া যাবে।

- **লোগো**: চাইলে `logo.svg` এর বদলে নিজের `logo.png`/`logo.jpg` আপলোড করে `index.html` এ এই লাইনটা খুঁজে বদলাও:
  `<img class="logo-img" src="logo.svg" ...>`
  → `src="logo.png"` (বা তোমার ফাইলের নাম যা দেবে)

## এডমিন প্যানেলে যা যা করা যায়

- বিদ্যমান পণ্যের দাম, স্টক, ছবি, ভ্যারাইটি এডিট/মুছে ফেলা

- সব ডিফল্টে ফিরিয়ে দেওয়া (রিসেট বাটন)
